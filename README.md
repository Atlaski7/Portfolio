# RJSD Portfolio

My portfolio work is here.

This workspace contains two separate areas:

- `app/`, `public/`, and the root package files: the portfolio website
- `discord-bot/`: the separate Discord bot workspace

## Run the portfolio

```bash
npm install
npm run dev
```

The portfolio is built with React, Vinext, and Tailwind CSS. Keep bot-only
code, dependencies, and environment variables inside `discord-bot/`.
